# QQBot CLI

通过 `qqbot-cli` 命令完成配置、注册和发送，根据命令输出判断结果。不要直接读取、搜索或修改程序内部使用的配置及用户数据，也不要通过浏览本地目录排查这些数据。缺少信息时询问用户，不猜测收件人，不发送凭据或未经授权的内容。

## 1. 定位可执行程序

可执行程序位于本技能目录的 `bin/` 下。Linux / macOS 使用 `bin/qqbot-cli`，Windows 使用 `bin/qqbot-cli.exe`。下文用 `qqbot-cli` 简写该程序；执行时替换为实际的绝对路径，无需加入 `PATH`。PowerShell 通过 `&` 调用带引号的程序路径。

```bash
qqbot-cli --version
qqbot-cli --help
```

仅在找不到可执行程序时执行文末的固定版本下载脚本。程序存在但无法执行时，检查该程序的执行权限或架构；配置、鉴权或发送错误不要通过重复下载处理。

## 2. 配置机器人

需要配置时，使用程序提供的命令：

```bash
qqbot-cli config --help
qqbot-cli config --app-id '<APP_ID>' --client-secret '<CLIENT_SECRET>'
```

缺少凭据时，优先提示用户自行执行配置命令，不在回复中暴露凭据。重新配置前先获得用户确认，不自行查找现有凭据。

## 3. 使用收件人，必要时注册

使用用户指定的已注册用户名作为收件人，而不是 QQ 号或昵称。直接执行请求的发送命令，由程序判断用户名是否已注册；不要通过读取本地数据确认注册状态。

若程序提示收件人尚未注册，先询问用户是否注册，并提醒目标用户准备向机器人发送私聊消息，再执行：

```bash
qqbot-cli register 'alice' --timeout 60
```

注册默认等待 10 秒，`--timeout` 必须是正整数。程序会将等待期间收到的**第一条私聊消息**的发送者绑定到指定用户名；提醒目标用户及时发送消息，并避免其他人同时私聊。成功时输出 `已注册用户 alice`。再次注册同名用户会覆盖绑定，先获得用户确认。

## 4. 发送消息或本地文件

仅使用用户指定的收件人、消息和待发送路径。参数不明确时先询问，不扫描本地内容寻找附件。使用独立参数传入用户名、完整消息和文件路径，不把用户内容拼接为可执行的 shell 代码。

```bash
qqbot-cli send text 'alice' '你好，任务已完成。'
qqbot-cli send file 'alice' '<用户指定的文件绝对路径>'
```

将占位参数替换为用户提供的值。优先使用绝对路径，相对路径以**调用时的工作目录**为基准。路径有效性由程序检查，无需读取待发送内容、手工上传、计算哈希或拆分分片。为带空格的参数加引号；复杂文本通过 shell 变量或进程参数数组传递，保留换行和特殊字符。

## 5. 核对执行结果

- 仅当退出码为 `0` 且输出 `发送成功` 时报告发送成功；这表示 API 请求成功，不代表收件人已读。
- 退出码非 `0` 时，依据命令输出报告失败原因，并隐藏凭据。提示用户未注册时询问是否注册；凭据缺失时提示用户通过配置命令处理。不要转而读取或搜索程序内部数据。
- 鉴权、权限、频率限制等以平台响应为准，不声称已绕过限制。
- 网络中断或超时时，发送结果可能不确定，不自动重试以免重复发送；说明情况并让用户决定是否重试。
- 使用 `qqbot-cli register --help`、`qqbot-cli send text --help`、`qqbot-cli send file --help`、`qqbot-cli config --help` 获取更多帮助；查看帮助和版本无需鉴权。

## 未找到可执行程序时：下载固定版本
> 当前仅提供 Linux x86_64、macOS Apple Silicon 和 Windows x86_64 版本。
若执行结果为“未找到可执行程序”，且已确认程序不存在，直接执行对应平台的下载脚本，无需读取脚本内容。脚本会下载可执行文件并统一保存为 `qqbot-cli`（Windows 为 `qqbot-cli.exe`），并运行 `--help` 验证。下载路径不受当前工作目录影响，也无需传入目录参数。

Linux x86_64 / macOS Apple Silicon（Bash，替换为本技能的实际绝对路径）：

```bash
bash "/absolute/path/to/qqbot-cli/scripts/download-qqbot-cli.sh"
```

Windows x86_64（PowerShell，替换为本技能的实际绝对路径）：

```powershell
& 'C:\absolute\path\to\qqbot-cli\scripts\download-qqbot-cli.ps1'
```

脚本成功后再执行原请求。若下载失败或返回 404，报告该固定版本或产物不可用，不将错误响应当作程序执行，也不自行寻找其他下载来源。
